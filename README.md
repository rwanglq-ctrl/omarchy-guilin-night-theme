# 桂林·夜 Guilin Night

漓江夜色为底、晨雾白为字、碧水青为印的深色主题。壁纸：漓江暮色、鸬鹚渔翁与龙脊梯田。

![preview](preview.png)

## 安装

```bash
omarchy theme install https://github.com/rwanglq-ctrl/omarchy-guilin-night-theme
```
